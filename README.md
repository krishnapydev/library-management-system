# Library Management System

A Python and SQLite project for managing library books, members, lending, returns, and reservations.

## Project Objectives

- Manage book and member records using SQL.
- Issue and return books while maintaining availability.
- Process reservations using a FIFO queue.
- Track recent actions using a LIFO stack.
- Validate functionality through automated software testing.

## Technologies

- Python
- SQLite
- Git and GitHub
- pytest

## Project Status

Currently in development as an MSc Computer Science seminar project.

## Learning Outcomes

This project demonstrates database management, data structures, object-oriented programming, and software testing.
